Import completed responses

Web-CDI can import CSV files created by the English-language MB-CDI fillable PDFs. Each row becomes a completed administration in this group. Column names must match these templates exactly:

  • English Words & Gestures
  • English Words & Sentences

You can also include demographic data by adding columns that match Web-CDI's fields — see this CSV of available fields, raw values, and their meanings, and these templates:

  • English Words & Gestures with demographics
  • English Words & Sentences with demographics

Notes: the name_of_child column becomes the Subject ID, so it must be numeric; a value that already exists in this group is treated as the same child and gets the next administration number. Expiration and last-modified dates come from date_today; the creation date is the import date, so creation can appear after expiration.
