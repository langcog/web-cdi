Get started

Welcome! Setting up data collection takes three steps:

  1. Select the CDI instruments you plan to use (some require a Brookes Publishing access code).
  2. Create an administration group — one per form, e.g. one group for Words & Gestures and one for Words & Sentences.
  3. Add administrations to the group and send participants their links.

The documentation walks through the whole workflow.
